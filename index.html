Trang Tĩnh (Static Serve) Port 80

Mọi yêu cầu đến đường dẫn / được Nginx xử lý trực tiếp tại thư mục /var/www/html/ với tốc độ phản hồi tối ưu.

location / {
  root /var/www/html;
  index index.html;
}
API Reverse Proxy Port 8082

Mọi yêu cầu có tiền tố /api/ được Nginx chuyển tiếp an toàn (Reverse Proxy) sang Backend Spring Boot đang chạy ở cổng 8082.

location /api/ {
  proxy_pass http://127.0.0.1:8082/;
  proxy_set_header Host $host;
}
